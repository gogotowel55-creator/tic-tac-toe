Project Name: ProjectTicTacToe

Desciption: A python-based program that uses functions to render the board and run the game logic. The board render uses the list[index] = " " method to display "x" and "o" in specific squares.
  The game logic uses a while loop to run the game as many times as it needs to and nested if-else statements to check if a square is already taken, if it's a tie, and more.

Features: 
- Fun with friends
- Easily repeatable:

Technologies Used
- Python
- Search Engine

How to Run: Open an online python compiler or any other option and paste the code into it. Run the code using F5 in the official Python compiler or click the run button.
